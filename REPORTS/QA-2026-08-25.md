## 4. Hidden-Content / Mobile Bugs

**Status: ✅ Clean**

### Reveal system (`[data-reveal]` + motion.js)
- `motion.css` sets `opacity:0` on `[data-reveal]` elements; `motion.js` adds the `.in` class via IntersectionObserver.
- **Threshold: 0.15 (15%)** — well below the risky ≥0.4 mobile cutoff. An element only needs 15% visible to trigger; no tall-element stuck-invisible risk.
- Fallback is in place: if `prefers-reduced-motion` or no IntersectionObserver, `.in` is added immediately.

### GSAP ScrollTrigger (index.html inline + ds/scroll.js)
- GSAP animates **transform only** (documented comment: *"reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."*)
- Triggers at `top 82%–88%` viewport — safe on mobile.
- `ScrollTrigger.refresh()` called both on `window load` and after 700ms to correct positions after fonts/images load.

No mobile black-gap / stuck-invisible risk identified.
