**Severity:** Medium  
**File:** `clinic-chatbot.html`

This standalone demo page for "Northview Psychology" has:
- No `<meta name="description">`
- No `<link rel="canonical">`
- No `og:*` or `twitter:*` tags
- No `<meta name="robots" content="noindex">`
- No `<h1>` tag
- Title set to `"Northview Psychology — AI Receptionist"` (client branding, not TRIVOX)

Google can discover and index this page through internal links, showing client branding with no meta description. This looks like a demo/internal tool that should either be noindexed or replaced with a TRIVOX-branded case demo.

**Fix (quick):** Add `<meta name="robots" content="noindex, nofollow">` to `<head>`.  
**Fix (proper):** Add TRIVOX-branded meta, canonical, and a proper `<h1>` if this page should be public-facing.
