## 4. Hidden-Content / Mobile Bugs

**✅ No high-risk reveal bugs found.**

- `[data-reveal]` pattern (motion.css + motion.js): IntersectionObserver threshold = **0.15** (15%) — very safe, elements reveal at 15% visibility on any screen size.
- Reduced-motion fallback: `@media (prefers-reduced-motion)` forces `opacity:1 !important` on all `[data-reveal]` — nothing can get stuck.
- GSAP scroll.js (v2.css pages): animates **transform only, no opacity** — confirmed by comment in scroll.js. Worst case = element doesn't slide, never goes invisible.
- `<section class="vault reveal" id="work">`: "reveal" here is a CSS class, not `[data-reveal]` attribute — not hidden by motion.css.
