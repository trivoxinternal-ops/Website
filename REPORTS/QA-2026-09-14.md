## 4. Hidden Content / Mobile Bugs ✅ CLEAN

**Reveal system analysis:**
- `[data-reveal]` in `motion.css` sets `opacity:0` + `translateY(26px)`, revealed by adding class `.in`
- `motion.js` uses `IntersectionObserver` with **`threshold: 0.15`** and `rootMargin: '0px 0px -8% 0px'`
- **threshold 0.15 is safe** — elements need only 15% intersection to reveal; no mobile black-gap risk
- Fallback: if no `IntersectionObserver` support, all reveals fire immediately (`.classList.add('in')`)
- `prefers-reduced-motion`: immediately reveals all elements with `opacity:1 !important` override in CSS

**GSAP/ScrollTrigger on index.html:**
- Comment in source explicitly notes: "reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."
- `ScrollTrigger.refresh()` called on `window.load` and after 700ms timeout — handles late-loading images/fonts
- Clean separation of concerns: GSAP handles transforms only, motion.js handles opacity ✅

No stuck-invisible risk identified.
