## 4. Hidden-Content / Mobile Bugs

**CLEAN — reveal system is safe.**

- `[data-reveal]` starts at `opacity:0; transform:translateY(26px)`, gets `.in` class via `IntersectionObserver`.
- **Observer threshold: 0.15 (15%)** — very permissive. Elements trigger when 15% is visible. No mobile stuck-invisible risk at this threshold.
- `rootMargin: '0px 0px -8% 0px'` — mild negative bottom margin, safe.
- GSAP ScrollTrigger controls **transforms only** (no opacity). The code comment confirms this is intentional: *"reveals animate TRANSFORM ONLY (no opacity). This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."*
- `prefers-reduced-motion`: both motion.css and motion.js honor it correctly — immediately adds `.in` class ✓
- `.svc-body` accordion starts `opacity:0; grid-template-rows:0fr` — this is intentional UI (hidden until user clicks). Not a bug.
