## 4. Hidden-Content / Mobile Bugs

**Reveal system (`[data-reveal]` + motion.js):**
- CSS: `opacity:0; transform:translateY(26px)` applied initially
- IntersectionObserver threshold: **0.15** (15%) with `rootMargin: '0px 0px -8% 0px'`
- On triggering: `.in` class adds `opacity:1; transform:none`
- Fallback for no-JS and reduced-motion: immediately adds `.in` ✅

**No mobile stuck-invisible risk.** Threshold of 0.15 is safe — far below the 0.4 danger zone. Even on small mobile viewports, 15% of an element entering the viewport is easy to achieve.

**GSAP animations (index.html only):**
The GSAP scroll triggers use `start:'top 82%'` to `start:'top 88%'` and animate only `y` transforms — NOT opacity. The comment in the source explicitly notes: *"reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."* ✅ Good defensive pattern.
