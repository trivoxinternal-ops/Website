## 4. Hidden-Content / Mobile Bugs

**Status: ✅ Clean — reveal system is safe**

**[data-reveal] pattern (motion.js):**
- Elements start `opacity:0; transform:translateY(26px)` via `motion.css`
- `motion.js` uses `IntersectionObserver` with `{ threshold: 0.15, rootMargin: '0px 0px -8% 0px' }`
- **Threshold is 0.15 (15%)** — very safe on mobile; element barely needs to enter the viewport to reveal
- Reduced-motion: all `[data-reveal]` elements immediately get class `.in` (opacity:1, transform:none) — safe

**GSAP scroll.js pattern:**
- Critically, `scroll.js` animates **TRANSFORM ONLY, not opacity**
- The comment explicitly states: "no element can ever get stuck invisible if a ScrollTrigger misfires — worst case it just doesn't slide"
- This design separation eliminates the black-gap risk

**No stuck-invisible risk identified on mobile.** Design is correctly hardened.
