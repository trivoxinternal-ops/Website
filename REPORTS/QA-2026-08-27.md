## 4. Hidden-Content / Mobile Reveal Safety

**Status: ✅ Clean**

The reveal system uses `motion.css` + `motion.js`:
- CSS sets `[data-reveal] { opacity: 0; transform: translateY(26px); }`
- JS uses `IntersectionObserver` with `threshold: 0.15, rootMargin: '0px 0px -8% 0px'`
- Threshold of **0.15** is safe — only 15% of an element needs to be visible to trigger. No tall-element-at-high-threshold mobile trap.
- `prefers-reduced-motion` fallback immediately forces `.in` class, bypassing reveal entirely ✅
- GSAP `ScrollTrigger.refresh()` called on `load` and after 700ms to handle font/image layout shifts ✅
- The vault section (`.vault`) uses `class="vault reveal"` on index.html — `reveal` class in motion.css only affects `will-change`, the actual hide/show is via `data-reveal` on children. No stuck-hidden risk.
