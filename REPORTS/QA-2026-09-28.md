## 4. Hidden-Content / Mobile Bugs

**Result: CLEAN — no high-risk patterns found**

- `[data-reveal]` elements use IntersectionObserver at `threshold: 0.15` (motion.js:20) — safe for mobile.
- GSAP scroll animations operate on `transform` only, NOT `opacity`. Comment in code confirms: "IMPORTANT: reveals animate TRANSFORM ONLY (no opacity)… guarantees no element can ever get stuck invisible if a ScrollTrigger misfires." (index.html:657)
- `@media(prefers-reduced-motion)` forces all `[data-reveal]` elements to `opacity:1 !important` — reliable no-JS / reduced-motion fallback ✅
- The only `threshold:0.5` IntersectionObserver is on `.metric .mv[data-count]` elements (tiny number counters for count-up animation) — these are not hidden page sections, so no risk of tall elements staying invisible.
- `.vault` section (id="work") uses `min-height:92vh` — large on mobile, but content is positionally absolute and not reveal-dependent. ✅
