## 3. Accessibility Basics

**Status: ⚠️ 2 findings**

## 4. Hidden Content / Mobile Bugs

**Status: ✅ Clean**

- `[data-reveal]` pattern uses IntersectionObserver at **threshold 0.15** with `rootMargin: '0px 0px -8% 0px'` (`ds/motion.js:20`). Threshold is well below the risky ≥0.4 zone — elements only need 15% visible to trigger, safe for mobile.
- `ds/motion.css:45` has `@media (prefers-reduced-motion: reduce)` rule that sets `opacity:1 !important; transform:none !important` on all `[data-reveal]` elements — solid safety net, nothing can stay invisible.
- `ds/scroll.js` comment explicitly notes: "IMPORTANT: reveals animate TRANSFORM ONLY (no opacity). Opacity fade stays with motion.js [data-reveal], so nothing can ever get stuck invisible if a ScrollTrigger misfires."
- No high-threshold or tall-section mobile-stuck risks found.
