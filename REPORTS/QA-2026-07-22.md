### ⚠️ ISSUE — clinic-chatbot.html (MEDIUM)
This demo page has **no meta description, no canonical, no og:* or twitter:* tags, and no robots noindex directive.** Google will index it and surface it as `"Northview Psychology — AI Receptionist"` — a fake demo clinic — under the trivox.ca domain. This dilutes brand identity, confuses search users, and leaks client-demo persona into TRIVOX's own Google results.

**Fix:** Add `<meta name="robots" content="noindex, nofollow">` in the `<head>`.

### ⚠️ ISSUE — privacy.html (LOW)
Missing meta description and canonical. Fine if you're happy with Google using the page title as the snippet, but a description would tighten it.

**Fix:** Add a one-line description + `<link rel="canonical">`.

## 4. Hidden Content / Mobile Bugs — ✅ CLEAN

### `[data-reveal]` pattern (motion.css + motion.js)
- Elements start `opacity:0; transform:translateY(26px)`.
- IntersectionObserver threshold: **0.15** (well below the risky ≥0.4 range that can get stuck on tall mobile sections).
- rootMargin: `'0px 0px -8% 0px'` — conservative, fires early.
- Accessibility: `prefers-reduced-motion` immediately adds `.in` and skips all transitions.
- Fallback for no-IO browsers: class added instantly.
- **No mobile stuck-hidden risk.**

### GSAP ScrollTrigger (index.html + sub-pages via scroll.js)
- Comment in index.html explicitly states: *"reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]."*
- This means GSAP and motion.js don't double-hide anything. Worst case a transform doesn't fire; opacity is never gated on GSAP.
- `ScrollTrigger.refresh()` called on `window.load` and again at 700ms — handles late-loading assets shifting layout.
- `.vault` section uses class `reveal` (not `[data-reveal]`), so it is **not** set to opacity:0 by CSS. GSAP handles its entrance transform only.
- **No dual-hidden or stuck-invisible risk.**
