## 4. Hidden-Content / Mobile Reveal Bugs

**Status: ✅ Clean**

The design system uses `[data-reveal]` (attribute selector, NOT `.reveal` class) with IntersectionObserver:
- **Threshold: 0.15** — safe. Only 15% of the element needs to enter the viewport to trigger reveal. No mobile sticky-invisible risk.
- **rootMargin: `0px 0px -8% 0px`** — mild negative offset, not aggressive.
- `prefers-reduced-motion` fallback present: all `[data-reveal]` elements get `.in` immediately with no animation. Correct.
- GSAP scroll.js (transform-only reveals, no opacity) used on sub-pages with ScrollTrigger — the inline comment explicitly notes this is safe: "Opacity fade stays with motion.js [data-reveal], so nothing can get stuck invisible if a ScrollTrigger misfires."

No mobile black-gap risk identified.
