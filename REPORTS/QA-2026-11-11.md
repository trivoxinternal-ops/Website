## 4. Hidden-Content / Mobile Bugs

**Result: CLEAN**

- `ds/motion.css` uses `[data-reveal]` → `opacity:0` pattern, activated by `.in` class added by `motion.js`.
- `ds/motion.js` uses `IntersectionObserver` with **`threshold: 0.15`** (safe — well below the ≥0.4 risk zone) and `rootMargin: '0px 0px -8% 0px'`.
- `prefers-reduced-motion` is handled: motion.css forces `opacity:1 !important` and `transform:none !important` for all `[data-reveal]` elements when reduced motion is preferred ✅
- `ds/scroll.js` (GSAP ScrollTrigger) animates **transform only, not opacity**, with an explicit comment in the source noting this is intentional so no element can ever be stuck invisible if ScrollTrigger misfires ✅
- No high-threshold reveals detected that could cause black gaps on mobile.
