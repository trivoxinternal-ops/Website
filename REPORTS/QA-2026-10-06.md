## 4. Hidden-Content / Mobile Bugs

**Reveal pattern — SAFE.**
- `motion.css` sets `[data-reveal]` to `opacity:0; transform:translateY(26px)`
- `motion.js` uses IntersectionObserver with **threshold: 0.15** (low — elements reveal at 15% visibility)
- `rootMargin: '0px 0px -8% 0px'` — triggers before element leaves viewport bottom
- `prefers-reduced-motion` respected: all reveals jump to `.in` state immediately
- No high-threshold (≥0.4) elements found — **no mobile stuck-element risk**

GSAP scroll animations (index.html) animate transform only, NOT opacity — comment in code confirms this is intentional to prevent stuck-invisible states.
