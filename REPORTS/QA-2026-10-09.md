## 4. Hidden-Content / Mobile Bugs (Reveal Patterns)

**Status: Clean — low-threshold observer, safe on mobile**

`motion.css` sets `[data-reveal]` to `opacity:0; transform:translateY(26px)` and adds `.in` class to restore it.

`motion.js` uses:
```js
new IntersectionObserver(callback, { threshold: 0.15, rootMargin: '0px 0px -8% 0px' });
```

**Threshold is 0.15 (15%)** — well below the danger zone. Elements need only 15% visibility to trigger, so tall sections on mobile are not at risk of staying hidden. The reduced-motion path also calls `el.classList.add('in')` directly, bypassing the observer entirely. No mobile reveal freeze risk detected.

GSAP scroll animations in `index.html` use `start: 'top 82%'` / `top 85%` thresholds, which fire well before the element is fully in view. No issues.
