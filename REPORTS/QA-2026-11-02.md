### 2. Stale Calendly booking URL in workflow-automation.html
All other pages use the canonical booking link `https://cal.com/trivox-interno-hfbm3x/trivox-discovery-call`. `workflow-automation.html` instead uses `https://calendly.com/trivoxinternal/intro-call` in **5 places**: the nav CTA, the hero CTA, 3 ledger rows, and the JSON-LD structured data `offers.url`.

If the Calendly link is dead or routes to the wrong calendar, every visitor on that page who clicks "Book a call" lands on a broken flow.

**Fix:** Replace all `calendly.com/trivoxinternal/intro-call` with `https://cal.com/trivox-interno-hfbm3x/trivox-discovery-call`.

## MEDIUM

### 3. clinic-chatbot.html — missing SEO and social meta
This page (a Northview Psychology chatbot demo) has no `<meta name="description">`, no canonical `<link>`, no `og:*` tags, no `twitter:*` tags, and no `<h1>`. If the page is indexed, it is a thin, unsocial page.

If this is an intentionally un-indexed demo embed, add `<meta name="robots" content="noindex">` to make intent explicit. If it should be a public page, add full meta.
