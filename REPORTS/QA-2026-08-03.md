## 4. Hidden-Content / Mobile Bugs — ⚠️ REAL ISSUE

### ISSUE: Mobile navigation completely hidden — no fallback menu

**Severity: High** (conversion impact on mobile)

In `ds/site.css`, line 55:
```css
@media(max-width:780px){.nav-links{display:none}.nav-in .btn{display:none}}
```

Both the navigation link list **and** the "Book a call" CTA button in the navbar are hidden on screens ≤780px wide. No hamburger menu, no drawer, no alternative mobile nav exists in any HTML file or JS. Mobile users (the majority of organic traffic) see only the TRIVOX logo in the sticky nav — no way to jump to sections or book a call from the top bar.

The hero CTA buttons (`Get started →` / `Book a free diagnostic`) are still visible in the hero section on all pages, so conversion is not completely blocked. But the sticky nav CTA disappears after scrolling past the hero.

**Recommendation:** Add a hamburger toggle + slide-out or stacked mobile nav. At minimum, make the "Book a call" button visible on mobile — it's your primary conversion point.

### Scroll-reveal animation — ✅ SAFE

- `[data-reveal]` starts at `opacity:0; transform:translateY(26px)` and is revealed by IntersectionObserver in `motion.js`.
- **Threshold: 0.15** (15%) — well within safe range. Low enough that even a taller section on mobile will trigger before 85% of the viewport passes.
- rootMargin: `0px 0px -8% 0px` — slight early-exit reduction, still safe.
- Fallback: if no IntersectionObserver support, all reveals are shown immediately.
- `prefers-reduced-motion`: handled correctly — all reveals shown instantly.
- No stuck-invisible risk found.

The `.vault.reveal` section uses GSAP for transform-only animation (no opacity: 0), so no invisible-content risk there either. The `svc-body` accordion uses `opacity:0` but that's intentional interactive state (not scroll-triggered).
