## 4. Hidden-Content / Mobile Bugs

**Result: CLEAN**

The `[data-reveal]` system (`motion.css` + `motion.js`):
- Hides elements with `opacity:0` + `translateY(26px)` via CSS attribute selector
- Reveals via IntersectionObserver with **`threshold: 0.15`** — well below the risky ≥0.4 level
- `rootMargin: '0px 0px -8% 0px'` — slightly early trigger, paired with 0.15 threshold this is mobile-safe
- GSAP layer (`scroll.js` / inline on index.html) only animates **transform, never opacity** — documented guard so no element can get stuck invisible if GSAP misfires
- `prefers-reduced-motion` fallback: all `[data-reveal]` elements immediately get `.in` ✓
- No-IO fallback: all get `.in` immediately ✓
- `ScrollTrigger.refresh()` called on `window.load` + 700ms timeout to resolve layout-shift stuck triggers ✓
- `.vault.reveal` section: `.reveal` only sets `will-change`, does NOT set `opacity:0` — not hidden by default ✓

No mobile hidden-section risk detected.
