## 4. Hidden-Content / Mobile Bugs

### ✅ Reveal animation system — safe for mobile
- `[data-reveal]` pattern uses `IntersectionObserver` with `threshold: 0.15` — well below the risky ≥0.4 range. No tall element should get stuck invisible on mobile.
- `motion.css` line 45 has a `prefers-reduced-motion` fallback that force-shows all `[data-reveal]` elements (`opacity:1 !important`), so a JS failure can't produce black gaps.
- `scroll.js` (GSAP ScrollTrigger) animates **transform only** (not opacity) — a missed trigger means no slide-in animation, but the element is always visible. Safe.
