## 4. Hidden-Content / Mobile Bugs — ✅ CLEAN

**Reveal system analysis:**
- `motion.css` sets `[data-reveal]` to `opacity:0; transform:translateY(26px)`. JavaScript adds class `.in` to reveal.
- `motion.js` uses `IntersectionObserver` with **`threshold: 0.15`** — safe on mobile. Only 15% of the element needs to be visible before it reveals. No risk of tall sections stuck hidden.
- `scroll.js` (GSAP ScrollTrigger) handles **transform only** (no opacity). As explicitly documented: "IMPORTANT: reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."
- `prefers-reduced-motion`: both motion.js and GSAP respect this, immediately revealing all elements or skipping animation.
- Conclusion: the two-layer pattern is deliberately safe. No mobile black-gap risk.
