## 4. Hidden-Content / Mobile Bugs

**Clean.** The reveal system is well-architected:

- `[data-reveal]` in `motion.css` starts elements at `opacity:0; transform:translateY(26px)`
- `motion.js` uses `IntersectionObserver` at **threshold: 0.15** with `rootMargin: '0px 0px -8% 0px'` — this is a low, safe threshold; elements reveal well before needing to be fully visible, so no mobile stuck-hidden risk
- `prefers-reduced-motion` support: when set, all reveals are immediately shown via `classList.add('in')` ✅
- On index.html, the GSAP `scroll.js` intentionally handles **transforms only** (not opacity), with a code comment explaining that opacity is left to motion.js to prevent stuck-invisible elements if ScrollTrigger misfires — good design choice
- The `.svc-body` accordion (`opacity:0; grid-template-rows:0fr`) is click-triggered, not scroll-triggered — correct behavior

No IntersectionObserver threshold risk, no tall elements with high thresholds, no mobile gap bugs identified.

### ⚠️ Low-priority issue
