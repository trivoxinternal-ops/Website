### SEO / Social Meta
9/11 pages have complete meta coverage (title, description, canonical, og:title, og:description, og:image, twitter:card, viewport). Exceptions are `clinic-chatbot.html` and `privacy.html` (noted above).

### Accessibility
- All 11 pages have `<html lang="en">`.
- All pages have exactly one `<h1>` except `clinic-chatbot.html` (no h1 — expected for a chat embed).
- No `<img>` elements missing an `alt` attribute across any page.

### Hidden Content / Mobile Reveals
- `[data-reveal]` pattern uses IntersectionObserver with **threshold: 0.15** — well below the risky ≥0.4 threshold. No tall-element mobile-stuck risk.
- `ds/scroll.js` (GSAP ScrollTrigger) animates **transform only** (not opacity), so no element can get stuck invisible even if a trigger misfires.
- `@media (prefers-reduced-motion: reduce)` overrides all reveals to `opacity:1 !important` — accessibility safe.

### Forms
No `<form>` elements on any page. All CTAs use `mailto:` links.

### Internal Anchors
`index.html` anchors `#about`, `#faq`, `#services`, `#store`, `#work` all have matching `id` attributes on the page. Nav `href="#"` void links are fine. No dangling anchors found.

### Internal Page Links
All `.html` cross-links resolve to existing files — except the two missing pages flagged above.
