## ⚠️ MEDIUM — Hidden Content Without JS (Global DS Pattern)

`[data-reveal]` elements across all 9 DS pages start at `opacity:0` via `ds/motion.css`. The `.in` class is applied by `ds/motion.js` via IntersectionObserver. Users with JavaScript disabled and `prefers-reduced-motion: no-preference` see all content sections as invisible.

- **Mitigation present:** `@media (prefers-reduced-motion: reduce)` sets `opacity:1 !important` — so accessibility users are safe.
- **IntersectionObserver threshold** on the metric count-up (index.html, `threshold:0.5`) applies only to `.mv[data-count]` animations, not to hiding full content sections — acceptable.
- **Known trade-off**, not a bug per se, but worth noting for accessibility audits.
