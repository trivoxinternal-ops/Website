## 4. Hidden-Content / Mobile Bugs

**motion.js IntersectionObserver threshold:** `0.15` (15%) with `rootMargin: '0px 0px -8% 0px'`
→ **Safe.** At 15% visibility the element reveals. Not a risk of elements staying permanently hidden on mobile.

**scroll.js / GSAP ScrollTrigger:** Uses `start: 'top 70%'` through `'top 88%'` for all animations.
→ **Transform-only animations.** The code explicitly comments: *"reveals animate TRANSFORM ONLY (no opacity). Opacity fade stays with motion.js [data-reveal], so nothing can ever get stuck invisible if a ScrollTrigger misfires — worst case an element just doesn't slide."*

**`.vault.reveal` section:** Uses class `reveal` (not `[data-reveal]`), so motion.js does NOT apply opacity:0 to it. No hidden-state risk.

**Result: Clean.** No mobile hidden-content bugs found.
