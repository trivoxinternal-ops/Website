## 4. Hidden-Content / Mobile Bugs

**Clean.**
- `data-reveal` pattern uses `IntersectionObserver` with `threshold: 0.15` (15%) — low threshold, safe on all mobile viewports
- `rootMargin: '0px 0px -8% 0px'` is mild; combined with 15% threshold, no risk of elements staying hidden
- `motion.css` includes `@media (prefers-reduced-motion: reduce)` fallback that forces all `[data-reveal]` elements visible immediately
- `scroll.js` (GSAP ScrollTrigger) uses **transform-only** animations — opacity is never set by GSAP, so no element can be permanently hidden if ScrollTrigger misfires
- Fallback for no IntersectionObserver support: all elements immediately receive `.in` class

No mobile reveal risk found.
