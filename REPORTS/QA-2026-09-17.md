## 4. Hidden-Content / Mobile Bugs

**✅ Clean — no stuck-hidden risk**

Reveal pattern used: `[data-reveal]` in motion.css sets `opacity:0; transform:translateY(26px)` with motion.js IntersectionObserver at **threshold: 0.15** and **rootMargin: '0px 0px -8% 0px'**.

- Threshold 0.15 is low — only 15% of the element needs to be visible to trigger reveal. Safe on mobile for tall sections.
- Fallback: `prefers-reduced-motion` forces `opacity:1 !important` immediately.
- Fallback: no IntersectionObserver support forces `.in` immediately.
- GSAP ScrollTrigger on index.html animates transform only (not opacity), with an explicit comment noting this is intentional so no element can get stuck invisible.
- `.vault.reveal` on index.html: class `.reveal` only sets `will-change:transform,opacity` — it does NOT start hidden. The section itself is always visible; only `[data-reveal]` children start hidden.
- `ScrollTrigger.refresh()` called both on `window.load` and after 700ms timeout to fix stuck-hidden sections after fonts/images load.

No mobile stuck-hidden risk identified.
