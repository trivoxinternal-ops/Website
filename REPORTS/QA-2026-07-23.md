## 4. Hidden-Content / Mobile Reveal Bugs — ✅ CLEAN

**IntersectionObserver threshold (motion.js):** `0.15` (15%) with `rootMargin: '0px 0px -8% 0px'`  
→ Well under the risky ≥0.4 threshold. No tall element will get stuck invisible.

**GSAP scroll triggers (scroll.js / index inline):**  
All triggers use `start: 'top 78–88%'` — conservative thresholds that fire before elements are deep in the viewport.

**Key design safeguard (confirmed in scroll.js comment + index inline):**  
GSAP animates **transform only**; opacity is handled exclusively by `motion.js [data-reveal]`. Even if a ScrollTrigger misfires, elements will never be stuck invisible — worst case they skip the slide animation. This is a deliberate and correct implementation.

No mobile reveal bugs found.
