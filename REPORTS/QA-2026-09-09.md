## 4. Hidden-Content / Mobile Bugs

**Clean.** No mobile-hidden-section risk found.

- `[data-reveal]` in `motion.css` sets `opacity:0 + translateY(26px)`, removed when `.in` class is added by `motion.js`
- `motion.js` uses `IntersectionObserver` at **threshold: 0.15** with `rootMargin: '0px 0px -8% 0px'` — well below the risky ≥0.4 threshold, so no mobile black-gap risk
- `scroll.js` (GSAP ScrollTrigger) **only animates transforms, never opacity** — by design, so nothing can get stuck invisible if a trigger misfires
- Both scroll scripts call `ScrollTrigger.refresh()` after `window.load` + a 700ms timeout to handle layout shift from webfonts/images
- The `.vault.reveal` class on `#work` in index.html uses a plain `.reveal` CSS class (just `will-change`), not `data-reveal` — no hidden state involved ✅
