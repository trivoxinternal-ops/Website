## 4. Hidden-Content / Mobile Reveal Bugs

**✅ CLEAN — No mobile stuck-hidden risk**

- `[data-reveal]` elements use IntersectionObserver with `threshold: 0.15` and `rootMargin: '0px 0px -8% 0px'` — well below the 0.4 risk threshold. Elements will reveal safely on all screen sizes.
- GSAP `ScrollTrigger` animations use `start: 'top 78%–88%'` — all safe, no hidden-until-scrolled issue.
- **By design:** the code explicitly separates concerns — GSAP handles transform-only animation; `motion.js` handles opacity via `[data-reveal]`. The comment in both `scroll.js` and `index.html` confirms: *"reveals animate TRANSFORM ONLY (no opacity) — worst case an element just doesn't slide."* No element can be stuck invisible if a trigger misfires.
- Service accordion bodies (`svc-body`) start `opacity:0` deliberately and are shown on click — correct JS-driven interaction, not a bug.
