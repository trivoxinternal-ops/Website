### ⚠️ ISSUE: `clinic-chatbot.html` — Missing all SEO meta, no noindex

`clinic-chatbot.html` is a publicly accessible chat demo at `trivox.ca/clinic-chatbot.html`. Its `<title>` reads **"Northview Psychology — AI Receptionist"** (a demo persona), and it has:
- **No `<meta name="description">`**
- **No `<link rel="canonical">`**
- **No `og:*` or `twitter:*` tags**
- **No `<meta name="robots" content="noindex">`**

Search engines can crawl and index this page. If shared on social media, it will show as a blank card. More importantly, Google may present it as a real clinic page (client persona) rather than a TRIVOX product demo, which is confusing for SEO authority on `trivox.ca`.

**Fix:** Add `<meta name="robots" content="noindex, nofollow">` to the `<head>`, or alternatively add proper TRIVOX-branded meta so it's clear this is a demo.

## 4. Hidden Content / Mobile Bugs

**Status: ✅ Clean**

### Reveal system analysis

`[data-reveal]` → `motion.css` sets `opacity:0; transform:translateY(26px)`. The IntersectionObserver in `motion.js` uses `{ threshold: 0.15, rootMargin: '0px 0px -8% 0px' }`. At 15% threshold, even tall sections on mobile will trigger as soon as 15% is visible — no stuck-hidden risk.

### GSAP animation architecture

Critical design note (documented in source code itself):
> "IMPORTANT: reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."

Both `scroll.js` (service pages) and `index.html`'s inline GSAP block call `ScrollTrigger.refresh()` at page load AND at 700ms, guarding against layout shifts from late-loading fonts/images.

GSAP `start` thresholds used: `82%`, `70%`, `78%`, `84%`, `85%`, `88%` — all conservative enough to trigger well before an element needs to be seen on typical mobile viewports.

The `vault` section uses class `reveal` (not attribute `[data-reveal]`), so its opacity is never suppressed — only GSAP transforms apply. Cannot get stuck invisible.

**No mobile-visibility bugs found.**

### ⚠️ ISSUE: `href="#"` Hours placeholder links (4 pages)

The CTA section on **index.html**, **ai-automation-toronto.html**, **ai-voice-agents.html**, and **workflow-automation.html** all contain:

```html
<span><span class="lbl">Hours</span><a href="#">Mon–Fri, 9–6 EST</a></span>
```

`href="#"` scrolls to the top of the page when clicked — the text feels like a link but does nothing useful. A visitor tapping "Mon–Fri, 9–6 EST" on mobile gets taken to the top of the page. Low priority, but easy to fix.

**Fix options:** Remove the `<a>` wrapper and keep it as plain text, or link to `mailto:info@trivox.ca` / `#faq`.
