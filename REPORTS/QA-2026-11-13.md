## 2. SEO / Social Meta

**9 of 11 pages clean.** Two pages have issues:

### ⚠️ ISSUE 1 — `clinic-chatbot.html`: No `noindex`, no SEO meta
- **File:** `clinic-chatbot.html`
- **Severity:** Medium
- **Detail:** This page is a client-facing chatbot demo widget for "Northview Psychology". It has zero SEO meta tags: no `<meta name="description">`, no `og:*`, no `twitter:*`, no `<link rel="canonical">`, and **no `<meta name="robots" content="noindex">`**. Without `noindex`, Google can crawl and index this page. It will appear in search results showing only "Northview Psychology — AI Receptionist" with no description — which is confusing and could embarrass the client.
- **Fix:** Add `<meta name="robots" content="noindex, nofollow">` to the `<head>`.

### ℹ️ NOTE — `privacy.html`: Missing meta description and og:* tags
- **Severity:** Low (privacy pages rarely appear prominently in search)
- **Detail:** No `<meta name="description">`, no `og:*`, no canonical, no `twitter:*`. Likely low impact but worth tidying.
- **Fix:** Add a short description and canonical tag.

All other 9 pages have: title ✓, description ✓, canonical ✓, og:title ✓, og:description ✓, og:image ✓ (all pointing to `assets/og-image.png` which exists), twitter:card ✓, twitter:image ✓, viewport ✓, favicon ✓.

## 4. Hidden-Content / Mobile Bugs (Scroll Reveal)

**Clean.** No high-threshold IntersectionObserver issue.

- Pattern: `[data-reveal]` elements start with `opacity:0; transform:translateY(26px)` (defined in `ds/motion.css`).
- Observer config in `ds/motion.js`: `threshold: 0.15, rootMargin: '0px 0px -8% 0px'`
- **Threshold 0.15 is safe** — only 15% of an element needs to be visible to trigger, so even tall sections on mobile viewports will animate in correctly.
- Fallback: if `IntersectionObserver` is unavailable, elements are revealed immediately.
- `prefers-reduced-motion` handled: reveals disabled via `opacity:1 !important` ✓
