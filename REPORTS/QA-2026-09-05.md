## 4. Hidden-Content / Mobile Bugs

### ✅ Reveal system is mobile-safe

- **`[data-reveal]` pattern** (`motion.css` + `motion.js`): Elements start `opacity:0; transform:translateY(26px)`. IntersectionObserver threshold is **0.15** (15%) — this is safe for mobile; elements reveal when only 15% enters the viewport.
- **`@media (prefers-reduced-motion)`**: Correctly overrides all `[data-reveal]` with `opacity:1 !important` — no content ever trapped invisible for reduced-motion users.
- **GSAP ScrollTrigger** (`scroll.js`): Uses `start: 'top 78%-88%'` markers (viewport-percentage, not element-percentage threshold). GSAP animates `transform` only — opacity is **not** animated by GSAP, per the scroll.js comment. If GSAP fails to load, the only downside is no slide animation — elements remain fully visible.
- **count-up observer in index.html (line 522)**: Uses `threshold: 0.5` for `.metric .mv[data-count]`. These are small metric-number elements (not full sections). Even at 50%, a small element typically crosses this on mobile. **Not a blackout risk.**
- **`@media (prefers-reduced-motion)` fix in motion.css**: Confirmed present (`[data-reveal]{ opacity:1 !important; transform:none !important; }`).
