## 4. Hidden-Content / Mobile Bugs

**⚠️ 1 real issue (mobile nav); reveal system is safe.**

### Reveal system analysis
- `[data-reveal]` elements start at `opacity:0` and are revealed by IntersectionObserver in `motion.js` at **threshold 0.15** with `rootMargin: '0px 0px -8% 0px'`. Threshold 0.15 is conservative and safe on all viewport sizes — no risk of tall elements staying permanently hidden on mobile.
- GSAP (`scroll.js`) animates **transform only**, not opacity. The explicit design comment in source: _"reveals animate TRANSFORM ONLY (no opacity) … guarantees no element can ever get stuck invisible if a ScrollTrigger misfires"_. This dual-layer safety is correct.
- `ScrollTrigger.refresh()` is called on `window.load` AND after 700ms on all pages that use GSAP — prevents stuck triggers after font/image layout shift. ✅
- The `.vault.reveal` section on index.html: `.reveal` class does NOT set `opacity:0` (it only sets `will-change`). GSAP animates `.vault-in > *` children with transform-only. Vault section is always visible. ✅

### ⚠️ Mobile nav — NO hamburger menu
`site.css` hides `.nav-links` and `.nav-in .btn` at ≤ 780px with `display:none`, but **there is no hamburger/drawer menu in the HTML or JS**. On mobile, the persistent nav shows only the TRIVOX logo wordmark — no navigation links and no "Book a call" CTA button.

**Impact:** Mobile visitors (likely 50–65% of traffic for a Toronto B2B site) cannot navigate to Services, FAQ, About, or initiate a booking from the nav bar. The hero section and footer provide partial compensation, but the persistent nav is functionally empty on mobile.

**Recommendation:** Either add a hamburger toggle with a drawer/dropdown, or add the primary CTA link back into the mobile nav at a minimum.
