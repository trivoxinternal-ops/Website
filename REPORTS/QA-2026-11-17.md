## 4. Hidden-content / Mobile Bugs — CLEAN ✅

- `[data-reveal]` elements use `opacity:0` + `translateY(26px)` via `motion.css`.
- `motion.js` IntersectionObserver uses `threshold: 0.15` with `rootMargin: '0px 0px -8% 0px'` — safe on all screen sizes, well below the ≥0.4 risk threshold.
- GSAP/ScrollTrigger reveals (via `scroll.js`) animate transform-only; opacity is handled by `motion.js` exclusively, ensuring no element can get stuck invisible if ScrollTrigger misfires.
- `prefers-reduced-motion` handled correctly: all animated elements get immediate `.in` class without transitions.
- The `.vault.reveal` section on index.html uses `.reveal` (not `[data-reveal]`); that class only applies `will-change` — it does NOT start hidden.
