## 4. Hidden-Content / Mobile Bugs — ✅ CLEAN

- `ds/motion.js` IntersectionObserver uses `threshold: 0.15` — well below the risky ≥ 0.4 threshold. No mobile stuck-invisible risk. ✅
- `ds/motion.css` has `@media (prefers-reduced-motion)` override: `opacity:1 !important` — elements cannot get permanently stuck hidden. ✅
- `ds/scroll.js` explicitly uses **transform-only animations** (no opacity changes): "nothing can ever get stuck invisible if a ScrollTrigger misfires." ✅

## 5. Forms — ⚠️ 1 MINOR ISSUE

Marketing pages use `mailto:` links for contact (no `<form>` elements) — acceptable pattern. ✅

**clinic-chatbot.html line 397:**
```html
<input type="text" class="chat-input" id="chatInput" placeholder="Type your message..." autocomplete="off">
```
This input **lacks a `name` attribute**. It's a JS-driven chat interface (not a traditional form POST), so it won't break functionality. However, it's best practice to add `name="message"` for accessibility/form-autofill tooling.

### index.html — ⚠️ 1 DANGLING ANCHOR

**Line 480:**

The `href="#"` on the "Hours" value is a dangling empty anchor. Clicking it scrolls the user to the top of the page. **Recommendation:** Remove the `<a>` wrapper and render as plain text, or link to `#contact` / `mailto:info@trivox.ca`.
