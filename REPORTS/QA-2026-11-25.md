## 4. Hidden-Content / Mobile Bugs

### ✅ Reveal system is safe
- `[data-reveal]` elements use **threshold: 0.15** (15% intersection required) — this is a LOW and safe threshold; elements will reveal well before they need to be fully in view.
- `rootMargin: '0px 0px -8% 0px'` adds a small bottom margin but does not cause stuck elements.
- `scroll.js` (GSAP ScrollTrigger) animates **transform only, no opacity** — explicitly designed so a ScrollTrigger misfire cannot hide content permanently.
- `prefers-reduced-motion` fallback immediately reveals all `[data-reveal]` elements ✓
- No high-threshold (≥0.4) IntersectionObserver risk found.
