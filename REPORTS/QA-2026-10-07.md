## Issue 4 — LOW: clinic-chatbot.html has no SEO meta

`clinic-chatbot.html` is a demo chatbot page with no SEO protection. It is publicly indexable (no `noindex` set). It is missing:
- `<meta name="description">`
- `<link rel="canonical">`
- og:title, og:description, og:image, og:url
- twitter:card, twitter:image
- `<link rel="apple-touch-icon">`
- No `<h1>` (by design, as a chat app)

If this page should not be indexed, add `<meta name="robots" content="noindex, nofollow">`. If it should, add the missing meta.
