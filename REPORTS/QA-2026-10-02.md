## 4. Hidden-Content / Mobile Bugs

**✅ Reveal system is safe.**

- `motion.css` sets `[data-reveal]` to `opacity:0` + `translateY(26px)`, resolved by `motion.js` IntersectionObserver at `threshold: 0.15` (15%). Very safe threshold — unlikely to get stuck on any mobile viewport.
- GSAP (`scroll.js` / inline scripts) animates `transform` only, never `opacity`. Comment in both files explicitly documents this: *"reveals animate TRANSFORM ONLY (no opacity)… nothing can ever get stuck invisible if a ScrollTrigger misfires."*
- The `vault` section (`class="vault reveal"`) uses a `.reveal` utility that is only `will-change:transform,opacity` — no opacity:0 — so it is always visible.
- `ScrollTrigger.refresh()` is called both on `window load` and with a 700ms timeout to handle layout shifts from image/font loading.

No hidden-content or mobile black-gap risk detected.
