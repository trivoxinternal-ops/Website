## 4. Hidden-content / Mobile Bugs

**Status: CLEAN**

Reveal system analysed:

- **motion.css**: `[data-reveal]` → `opacity:0; transform:translateY(26px)`. Cleared when `.in` class is added.
- **motion.js**: IntersectionObserver with `threshold: 0.15` and `rootMargin: '0px 0px -8% 0px'`. Both values are conservative and safe on mobile.
- **GSAP scroll animations** (scroll.js + inline in index.html): Animate **transform only**. Opacity is delegated to motion.js `[data-reveal]`. This is an intentional design that prevents elements from getting stuck invisible if GSAP misfires — well-engineered.
- No IntersectionObserver with `threshold >= 0.4` found.
- The `.vault` section on index.html has class `reveal` (not `[data-reveal]`), which only sets `will-change` — always visible. Correct.
- The `.svc-body` accordion (`opacity:0; grid-template-rows:0fr`) requires a user click, not a scroll position — not a mobile bug.

**No mobile invisible-content risk found.**
