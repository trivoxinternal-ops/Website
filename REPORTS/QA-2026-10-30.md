## 4. Hidden-Content / Mobile Bugs

**Clean.**
- `[data-reveal]` uses `opacity:0; transform:translateY(26px)` as start state.
- `motion.js` IntersectionObserver: **threshold 0.15** (low — only 15% of element needs to be visible). Well below the risky 0.4 threshold. Not a mobile risk.
- `rootMargin: '0px 0px -8% 0px'` — fires when element is 8% above viewport bottom.
- index.html GSAP ScrollTrigger is transform-only per explicit comment: *"reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."*
- `.vault.reveal` class does NOT add `opacity:0` — only `will-change` — so the vault section cannot get stuck hidden.
