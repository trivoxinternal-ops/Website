## ✅ 4. Hidden-Content / Mobile Bugs — CLEAN

**Reveal pattern:** `[data-reveal]` in `motion.css` starts at `opacity:0; transform:translateY(26px)` and is revealed by `motion.js` via IntersectionObserver with **threshold: 0.15** and rootMargin `-8% 0px`. Threshold 0.15 is safe for mobile — elements only need 15% in view to trigger.

**GSAP layer:** The index.html GSAP script explicitly notes "reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js" — this is a deliberate safeguard. No element can get stuck invisible from a GSAP misfiring.

**Vault section:** `section.vault` has class `reveal` (not `[data-reveal]`) — this only sets `will-change:transform,opacity`, not `opacity:0`. It is always visible. GSAP animates from y:52 on enter but cannot hide it.

**Reduced-motion:** motion.css includes `@media(prefers-reduced-motion:reduce)` that forces all reveals visible immediately ✅

No mobile black-gap risk found.
