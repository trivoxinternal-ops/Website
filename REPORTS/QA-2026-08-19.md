## 4. Hidden-Content / Mobile Bugs

- **`[data-reveal]` pattern** (opacity:0 → revealed by IntersectionObserver): threshold is **0.15** (15%) with `rootMargin: '0px 0px -8% 0px'`. This is a safe, mobile-friendly threshold — a short element only needs 15% in view to trigger, so no realistic risk of permanently hidden sections on mobile.
- **GSAP ScrollTrigger** (scroll.js / inline in index.html): explicitly animates `transform` only, NOT `opacity`. Comment in codebase: *"so nothing can ever get stuck invisible if a ScrollTrigger misfires"*. Design is deliberately safe.
- **`.vault` section** (`id="work"`) uses class `reveal` (not `data-reveal`). The CSS `.reveal{}` only sets `will-change` — **no opacity:0 applied** — so it's always visible. GSAP handles transform-only slide-in for vault children. ✅ No mobile-invisible-section risk.
- **Reduced-motion**: both motion.js and scroll.js correctly respect `prefers-reduced-motion`. ✅

**Clean** on mobile/reveal bugs.
