## 4. Hidden-Content / Mobile Bugs — ✅ Clean

**Reveal system:** `[data-reveal]` elements start `opacity:0; transform:translateY(26px)` (via `motion.css`).

**IntersectionObserver** in `motion.js`: `threshold: 0.15, rootMargin: '0px 0px -8% 0px'`  
✅ Threshold 0.15 is mobile-safe — only 15% of the element needs to be visible. No risk of elements staying hidden on small viewports.

**GSAP (scroll.js / inline index.html script):** explicitly only animates `transform` (not opacity). Code comment confirms: *"reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires."*

No high-threshold IO patterns, no opacity-stuck-on-scroll risks found.
