## 4. Hidden-Content / Mobile Bugs ✅ Clean

- `[data-reveal]` pattern uses `IntersectionObserver` with **threshold: 0.15** and `rootMargin: '0px 0px -8% 0px'` — safe on mobile. No risk of elements staying hidden.
- `motion.css` line 45 sets `[data-reveal] { opacity:1 !important; ... }` under `prefers-reduced-motion` — correct fallback, elements always visible.
- `scroll.js` uses **transform-only** (no opacity) for GSAP ScrollTrigger animations — explicitly designed so nothing can get stuck invisible if ScrollTrigger misfires.
- No high-threshold (≥0.4) observer patterns found.

No mobile/JS-failure visibility risks detected.
