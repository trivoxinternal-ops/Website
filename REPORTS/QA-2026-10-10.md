## 4. Hidden-content / Mobile Animation

**Clean.** The reveal system is safe:

- `[data-reveal]` starts at `opacity:0` + `translateY(26px)` (motion.css)
- Revealed by IntersectionObserver at **threshold: 0.15** with `rootMargin: '0px 0px -8% 0px'` (motion.js) — well below the 0.4 risk threshold
- `prefers-reduced-motion` override: CSS forces `opacity:1 !important` so no element can get stuck invisible
- No-IO fallback: `reveals.forEach(el => el.classList.add('in'))` — safe on older browsers
- scroll.js (GSAP ScrollTrigger) animates **transform only** (no opacity), per inline comment: "Opacity fade stays with motion.js [data-reveal], so nothing can ever get stuck invisible if a ScrollTrigger misfires"

No mobile black-gap risk identified.
