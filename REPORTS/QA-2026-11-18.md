**Issue (medium) — clinic-chatbot.html missing all SEO meta:**

- **Fix:** Add `<meta name="robots" content="noindex, nofollow">` to clinic-chatbot.html, or add proper TRIVOX-branded meta if it should be indexed.

## 4. Hidden-Content / Mobile Bugs

**Clean.** The reveal system uses:
- `[data-reveal]`: starts at `opacity:0; transform:translateY(26px)` via `motion.css`
- Triggered by `IntersectionObserver` in `motion.js` at **threshold: 0.15** (15%) with `rootMargin: '0px 0px -8% 0px'`

Threshold of 0.15 is well below the ≥0.4 risk threshold. No stuck-invisible-on-mobile risk flagged.

GSAP on `index.html` correctly handles only `transform` (not `opacity`), per inline comment: "reveals animate TRANSFORM ONLY (no opacity). Opacity fade is handled by motion.js [data-reveal]. This guarantees no element can ever get stuck invisible if a ScrollTrigger misfires." ✓

`ScrollTrigger.refresh()` is called on `window.load` and after a 700ms timeout on index.html. ✓

The `.vault` section uses `class="reveal"` (not `[data-reveal]`), and `motion.css` has no opacity:0 on `.reveal`, only `will-change`. Not a hidden-content risk. ✓
